💬 IM 📷 图片上传 👥 创建群聊 📢 @所有人
你
把"周建锋和王佳宝"拉个群，群名叫"CLI需求评审群"，把 Downloads 里的图发到群里，@所有人 KM 相关逻辑更新，具体查看 PRD"CLI 二期需求"，把链接也发过去
AI
已完成 5 步操作
  • 解析"周建锋"、"王佳宝"为 POPO 账号
  • 创建群聊「CLI需求评审群」，自动入群
  • 读取本地图片并上传到 POPO FP
  • 在群内 @所有人 发送公告 + 图片
  • 检索 PRD 文档「CLI 二期需求」并附上链接 ✅
📝 CASE 02 · PRD 智能续写 + 同步评审

已完成文档续写 + 群内通知
  • 定位文档「CLI 二期需求 副本」目标章节
  • 补充：适用范围 / 触发时机 / 兼容流程 / 用户文案 / 与 POPO 授权一致性说明 / 异常兜底
  • 插入到原章节之后，保留原有标题结构
  • 在「CLI 需求评审群」@周建锋 发送变更说明 + 文档链接 ✅
🔍 CASE 03 · PRD 逻辑漏洞自动批注

让 AI 当你的预评审助手

📄 云文档 🧠 逻辑分析 💡 原地批注 ⚠️ 评审兜底
你
查看「CLI 二期需求 副本」文档，分析 PRD 中的逻辑漏洞，把问题加在对应位置展示
AI
已完成全文逻辑评审
  • 读取文档全文 + 解析章节结构
  • 定位逻辑薄弱点（如"关键字匹配规则"的二义性）
  • 在对应段落后插入 [评审] 批注块（高亮卡片样式）
  • 例：关键字匹配发生在「URL 替换前」还是「替换后」？若替换后再匹配，搜 popofp 会误命中 URL ✅
